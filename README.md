# Калькулятор сроков 3-й линии

Небольшой статический сайт с двумя режимами:

- SLA-калькулятор с заданными правилами расчёта срока;
- калькулятор календарных и рабочих дней с расчётом интервала и дат в обе стороны.

Сервер, база данных и сторонние API для расчётов не используются. Государственные
праздники пока не учитываются: рабочими считаются понедельник–пятница.

## Что воспроизведено из калькулятора дней

Перед реализацией была изучена механика
[fincalculator.ru/kalkulyator-dnej](https://fincalculator.ru/kalkulyator-dnej):

- две редактируемые даты и два календаря;
- переключатель включения конечной даты;
- общее количество дней;
- количество рабочих дней;
- представления «недели + дни», «месяцы + дни» и «годы + месяцы + дни»;
- расчёт конечной даты от начальной по любому виду интервала;
- обратный расчёт начальной даты от конечной;
- выбор направления по последней изменённой дате;
- день года, номер календарной недели и словесное положение дня в месяце.

В этой версии рабочие дни намеренно определяются только по правилу Пн–Пт, без
производственного календаря и праздников.

## Структура

```text
dist/
  index.html        интерфейс
  styles.css        адаптивное оформление
  app.js            состояние и работа с DOM
  calculations.js   чистый расчётный движок
tests/
  calculations.test.mjs
.github/workflows/pages.yml
```

## Локальный запуск

```bash
python -m http.server 8000 --directory dist
```

После запуска откройте `http://localhost:8000`.

## Проверка

```bash
npm test
```

Тесты выводят таблицу `Вход | Тип | Ожидается | Получено | Статус` и завершаются
ошибкой при любом несовпадении.

## GitHub Pages

Workflow автоматически запускает расчётные тесты и публикует содержимое `dist`
при каждом push в `main`. В настройках нового репозитория нужно выбрать Pages →
Source → GitHub Actions.
